# 建设银行App模拟版

这是一个使用Flutter框架开发的中国建设银行App模拟版应用。该应用仅用于学习和演示目的，不包含任何实际的银行功能。

## 功能特点

- 模拟建设银行App的主页界面
- 包含各种银行常见功能的布局
- 响应式设计适配不同尺寸的屏幕

## 开始使用

### 前提条件

- 安装Flutter SDK (3.0.0或更高版本)
- 安装Android Studio或Visual Studio Code
- 配置好Flutter开发环境

### 安装

1. 克隆这个仓库
2. 运行 `flutter pub get` 安装依赖
3. 运行 `flutter run` 启动应用

## 项目结构

- `lib/main.dart` - 应用入口
- `lib/home_page.dart` - 首页界面实现
